# Учитель этапа 2: процедура

Документ для треда-учителя. Без кода: учитель правит навыки и ничего больше.

**Как запускают.** Хозяин пишет в чате проекта «учитель». Координатор открывает тред и даёт ему этот документ.

**Группы проверки** (`controlBots: 2`, `bots: 10`): А — HC_1–HC_5 (учатся с правкой), Б — HC_6–HC_8 (учатся без правки), контроль — HC_9, HC_10 (без общей памяти и без проб). Сравниваем А с Б: учатся они одинаково, разница только в правке.

## 1. Что прочитать

- `hardcore/data/skills_report.md` — сводка по делам за последние миры. Если её нет или она старая: `node hardcore/skills_report.js --worlds 5`.
- ленты последних трёх миров: HTML в `hardcore/data/timeline/`;
- причины смертей: `hardcore/data/lives.jsonl`, поля `cause` и `deathMessageServer`.

## 2. Какое дело править

- Не больше двух дел с самыми низкими средними очками: это внизу сводки, «Худшие 5 дел».
- Одна правка — одно дело.

## 3. Сначала готовое

Прежде чем писать свой код, ищем, как это дело решают другие боты на mineflayer:

- Voyager, Odyssey, `mc-fleet-bot` (разбор от 03.11), примеры mineflayer;
- лицензия MIT или Apache;
- в шапке файла правки — откуда взято и какая лицензия.

Свой код — только если готового нет. Это решение хозяина: чужой код брать можно и нужно.

## 4. Где правка

- Файлы правки — в `hardcore/teach/<id>/learned/`. `<id>` — короткий номер проверки, например `t1`.
- Файл — новая версия навыка `<база>_vN.js` или новый навык. Новый навык — его имя перечисляем в `offer`.
- Офлайн-тест на правку — в `test/`. `npm test` зелёный.

## 5. PR

- PR с файлами правки и строкой конфига `teach` в `hardcore/config.json`:
  `"teach": { "id": "t1", "offer": ["имя_нового_навыка"], "worlds": 3 }`. `offer` можно не указывать.
- PR ставит хозяин или Claude по его «да». Только между мирами: мир, который идёт, не трогаем.

## 6. Итог

- Через три мира читаем `hardcore/data/teach/<id>/result.json`: поле `verdict` и список `worlds` с Б и А по каждому миру.
- **«оставить»** — PR, который переносит файлы из `hardcore/teach/<id>/learned/` в `brain/learned/`. Сливает хозяин.
- **«откат»** — ничего не делаем: правка уже не выдаётся мухам.
- Хозяину — три строки: что правили, откуда взяли, А против Б.

## Учителю нельзя

- трогать стенд, очки, решатель, конфиг (кроме `teach`) и тесты чужих шагов. Учитель не чинит мерило вместо бота (`docs/goal_path.md`, этап 2, риски);
- больше двух правок за раз;
- новую правку, пока не вынесен вердикт по прошлой.

Подробный план этапа 2 и решения хозяина — в `docs/stage2_plan.md`.
