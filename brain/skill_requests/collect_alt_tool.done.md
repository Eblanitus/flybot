# collect_alt_tool: готово
Версия: collect_alt_tool
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=collect_alt_tool&block=cobblestone&count=27"
Params: block — имя блока для сбора (по умолчанию cobblestone); count — количество (по умолчанию 1); items — список в формате "block:count, ..." (альтернатива block/count); radius — радиус сбора (по умолчанию 48); deep — копать в глубину (true/false); style — стиль копки (auto).
Что делает: Собирает указанный блок или микс ресурсов (например, cobblestone + spruce_fence). Перед добычей блоков, требующих инструмент (cobblestone, stone и др.), проверяет наличие кирки и автоматически обеспечивает её создание (сбор брёвен, крафт досок, палок, верстака и деревянной кирки). Возвращает {ok: true, collected, crafted, sec} при успехе или {ok: false, error} при нехватке материалов.
Ограничения: Требует наличия деревьев/брёвен в радиусе досягаемости для крафта кирки, если её нет.
