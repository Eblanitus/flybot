# gather_list: готово
Версия: gather_list_v10 (на базе gather_list_v9)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=gather_list_v10&items=cobblestone:30"
Params: items — список предметов "имя:кол-во" или объект {имя:n}, max_sec — ограничение времени в секундах (по умолчанию 600), dry — 1 для возврата плана без выполнения.
Что делает: Добрать список предметов с автоматическим обеспечением инструмента (wooden_pickaxe). Если запрашиваются блоки, требующие кирку (булыжник, уголь, руды), и кирки нет — сначала добывает древесину (с автоматическим explore при поиске брёвен), крафтит доски, палки, верстак и деревянную кирку, а затем собирает нужные ресурсы. При успехе возвращает {ok: true, collected, crafted, have, missing:{}}, при провале — {ok: false, error} с причиной нехватки.
Ограничения: Требует доступности деревьев неподалеку или возможности explore для сбора начальных брёвен на кирку.
