Версия: новый вариант collect_alt_tool_v4 (та же цель — копать блоки, но с обеспечением инструмента спереди). отличается от collect_tool: гарантирует инструмент для ВСЕХ блоков в params.collect, а не только для первого; отличается от collect_alt_tool_v2: учитывает специфическую ошибку «wooden_pickaxe: не хватает: wo» (не хватает木ля, а не просто инструмента); отличается от обычного collect: встроен шаг обеспечения инструмента спереди.

Что нужно (не код):
- skill `collect` должен проверять, нужен ли инструмент для каждого блока в params (cobblestone, stone, coal_ore и др.)
- если инструмента нет — skill должен сначала обеспечивать инструмент: spruce_log (ломается голыми руками) → spruce_planks → stick → crafting_table → wooden_pickaxe, и только тогда копать requested block
- если брёвен рядом нет или не хватает доски/палок — честный отказ с причиной «нет брёвен для крафта кирки», а не «нужен инструмент»
- в ответе должен быть видно, что инструмент был сделан (crafted: wooden_pickaxe) и сколько блоко собрано (collected.cobblestone / collected.stone)
- обеспечение инструмента не должно заканчиваться по причине «сначала нужен инструмент» — этот шаг встроен в сам skill
- если список можно выполнить без инструмента (только доски/брёвна, которые не нуждаются в кирке) — старая логика без инструмента работает

Вариант: новый вариант `collect_alt_tool_v4` — skill collect с обеспечением инструмента спереди для всех блоков списка. Подходит, когда требуются cobblestone (или stone, coal_ore) для постройки, а кирки нет (после смерти, в новом мире или после долгого простоя). отличается от collect_tool: проверяет ВСЕ блоки из params, а не только первый; отличается от collect_alt_tool_v2: учитывает ошибку «wooden_pickaxe: не хватает: wo» (недостаток wood logs, а не инструмента вообще); отличается от обычного collect: встроен шаг обеспечения инструмента спереди, который не возвращается как ошибка «нужен инструмент».

Простая до: 20 мин за сутки (текущий день 39), самый длинный 52 мин (days.log, день 39); построено за сутки: 0. Сравни с прошлой заявкой collect_tool.md: та затрагивает общий случай, а этот вариант specifically решает проблему «не хватает: wo» при крафте wooden_pickaxe.

Как проверить: запуск collect с block="cobblestone" при пустой сумке и рядом spruce_log → ok:true, в ответе crafted есть wooden_pickaxe, collected.cobblestone > 0; при отсутствии брёвен рядом — отказ с причиной про брёвна (не «нужен инструмент»); в brain/runner.log нет ошибок «нужен инструмент для cobblestone» и «wooden_pickaxe: не хватает: wo» после внедрения варианта; после collection в сумке растёт количество cobblestone; смерть предотвращается в схожих обстоятельствах.
