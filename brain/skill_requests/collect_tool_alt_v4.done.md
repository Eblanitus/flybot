# collect_tool_alt_v4: готово
Версия: collect_tool_alt_v4 (новая версия по заявке учителя)

Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=collect_tool_alt_v4&block=cobblestone&count=10"

Params:
- block — имя блока для сбора (cobblestone, stone, coal_ore и др.), по умолчанию cobblestone
- count — количество, по умолчанию 1
- items — список в формате "block:count, ..." (альтернатива block/count)
- radius — радиус сбора, по умолчанию 48
- deep — копать в глубину (true/false)
- style — стиль копки (auto и др.)

Что делает: 2–4 строки:
Skill collect_tool_alt_v4 проверяет, нужен ли инструмент для добываемого блока (cobblestone, stone, coal_ore и др.). Если инструмент нужен — обеспечивает деревянную кирку спереди цепочкой крафта: spruce_log → spruce_planks → stick → crafting_table → wooden_pickaxe. Шаг обеспечения инструмента встроен в skill и не возвращается как ошибка «нужен инструмент». Если брёвнов рядом нет или не хватает досок/палок — честный отказ с причиной «нет брёвен для крафта кирки», а не «нужен инструмент». После обеспечения инструмента сразу копает requested block. В ответе видно, что инструмент был сделан (crafted: wooden_pickaxe) и сколько блоко собрано (collected.cobblestone / collected.stone). При провалеcollect skill пытается обеспечить инструмент повторно, а не просто отказывается и переходит к explore.

Ограничения: навык не умеет копать без обеспечения инструмента спереди при наличии блоков, требующих кирку; если брёвна нет в инвентаре и вокруг — возвращает ошибку про недостаток木料; не возвращается как ошибка «нужен инструмент» — этот шаг встроен спереди; требует доступных брёвен (spruce) в радиусе сбора или в инвентаре для крафта кирки.

Схема обеспеченияTool: spruce_log (сломал голыми руками) → spruce_planks (крафт из 4 логов) → stick (крафт из 2 досок) → crafting_table (крафт из 4 досок) → wooden_pickaxe (крафт из 3 досок + 2 палок).
