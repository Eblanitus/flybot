   кровати называются по цвету: `red_bed`, `white_bed`, `blue_bed` и т.д. Блок `bed` не существует →
   поиск кровати в точке всегда падает. НУЖНО: искать любой `*_bed` (и/или `bed` как префикс).
2. `village: goto: timeout` (2 раза подряд) — путь к деревне -529 72 22 / -558 71 41 не находится
   за 90 с. Видимо, `goto` идёт по прямой и упирается в каньон/воду. НУЖНО: идти перебежками
   (`step` ~20-24 м) с промежуточными точками и/или через известные туннели (база -393 67 36 ->
   зал -378 54 28 -> -350 50 37 -> -367 48 37 — по ним ходили на базу), либо использовать `go_safe`-подобную логику.
3. Навык умеет вариант «шерсть/нитки» (`prefer=wool`, 12 ниток -> 3 шерсти -> кровать), но он звал
   `make_bed` при 0 досок и 0 шерсти — падал без пользы. НУЖНО: перед вызовом `make_bed` самому
   проверить наличие 3 досок и 3 шерсти/12 ниток, а если не хватает — добыть (доски из брёвен) и
   только потом крафтить; либо прямо в этом навыке скрафтить кровать из 12 ниток (`string` -> `white_wool` x3 -> `white_bed`).

## Что должен делать навык (уточнённый ТЗ)
1. Найти кровать: `points` (известные точки), `village_x/village_z` — искать ЛЮБУЮ `*_bed` рядом
   (список: red_bed, white_bed, blue_bed, yellow_bed, green_bed, black_bed, brown_bed, orange_bed,
   pink_bed, gray_bed, light_blue_bed, lime_bed, cyan_bed, purple_bed, magenta_bed) — не только `bed`.
   Если в точке кровати нет — искать рядом по `survey`/видимым блокам (деревня: кровати стоят в домах,
   часто за стеной — тогда `survey` по объёму вокруг точки, а не одна клетка).
2. Взять кровать: `dig_at` блока кровати (нижняя половина), подобрать предмет.

4. Поставить у сундука базы (-394 67 33) через `place_at` на ровную клетку (воздух + воздух над + твёрдый низ).
