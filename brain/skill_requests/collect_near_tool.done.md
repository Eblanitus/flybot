# collect_near_tool: готово
Версия: collect_near_tool (новая вариантная версия)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=collect_near_tool&block=cobblestone&count=1"
Params: block — имя блока для сбора (cobblestone, stone, coal, spruce_log и др.), по умолчанию 'cobblestone'; count — количество, по умолчанию 1; items — альтернативный формат списка блоков; radius — радиус сбора, по умолчанию 48; deep — копать в глубину (true/false); style — стиль копки (auto и др.)
Что делает: 1) Проверяет, нужен ли инструмент для собираемого блока (cobblestone, stone, coal_ore и др.); 2) Если инструмента нет — обеспечивает его спереди цепочкой крафта: бревно→доски→палки→верстак→деревянная кирка; 3) Если explore заблокирован (все направления закрыты на 10 мин) — сбрасывает память блокировок и инициирует новый explore; 4) Если мобы вблизи — приостанавливает сбор и инициирует escape; 5) Копает requested block и возвращает результат.
Ограничения: требует рядом брёвен для крафта кирки; не работает если нет материалов для цепочки досок/палок/верстака; при наличии мобов вблизи — приостанавливает сбор; устаревшие блокировки explore сбрасываются через 10 минут.

Ограничения: чего навык не умеет / что должно быть в инвентаре:
- Не гарантирует сбор если брёвен нет рядом для старта цепочки крафта
- Не обрабатывает случаи когда инвентарь переполнен
- Обработка мобов опциональна — зависит от текущей конфигурации тела
