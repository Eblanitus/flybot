# gather_list_tool_alt: готово
Версия: gather_list_tool_alt
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=gather_list_tool_alt&items=cobblestone:32"
Params: items — список "имя:кол-во,…" или объект {имя:n} (stone=cobblestone, log=брёвна, planks=spruce_planks); max_sec — ограничение времени (по умолчанию 600); dry — 1: только план
Что делает: Добирает список предметов. Если в списке есть предметы, требующие кирку (cobblestone, stone, coal, руды), и кирки нет — сначала проверяет доступность брёвен в инвентаре или поблизости. Если брёвен нет — честный отказ: "нет брёвен для крафта кирки (нужен spruce_log xN)". Если есть — craft-цепочкой делает wooden_pickaxe, затем collect. В ответе при успехе есть crafted.wooden_pickaxe; при отсутствии материалов — ошибка про отсутствие брёвен, а не "нужен инструмент". Сборы без инструмента (доски/брёвна) работают без этого шага.
Ограничения: Не умеет крафтить каменную/железную кирку (только деревянную). Требует spruce/oak/birch_log для крафта. Не ищет брёвна далеко — только инвентарь + ближайшие блоки (eyes.blocks).
