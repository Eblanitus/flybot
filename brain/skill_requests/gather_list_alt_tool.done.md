# gather_list_alt_tool: готово
Версия: gather_list_alt_tool_v2 (на основе gather_list_alt_tool_v1)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=gather_list_alt_tool_v2&items=cobblestone:16"
Params: items — список предметов ("имя:кол-во,…"); max_sec — ограничение времени, по умолчанию 600; dry — 1 только план.
Что делает: Добрать список предметов (в т.ч. требующих кирку: камень, уголь, руду). Если нужного инструмента нет, сначала автоматически обеспечивает кирку (собирает брёвна, крафтит доски, палки, верстак и деревянную кирку), а затем добывает требуемые ресурсы и выполняет крафт. Возвращает `{ok: true, collected, crafted}` при успехе или `{ok: false, error}` с причиной при нехватке ресурсов.
Ограничения: Требует наличия деревьев поблизости для создания инструментов при их отсутствии; без читов.
