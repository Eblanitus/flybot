# climb_up: готово
Версия: climb_up_v7 (основа — climb_up_v5 по заявке)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=climb_up_v7&target_y=72"
Params: x,z — цель по горизонтали; y | target_y — абсолютная высота цели (при конфликте разных значений — отказ с вопросом); to_y — на сколько вверх; ground=1 — поверхность у цели; steps (40); item; need; min_ratio (0.6); strict (1); max_sec (240); mob_d (6) — порог остановки по мобу; dry=1 — смета (пустой прогон, не растит счёт).
Что делает: подъём вверх лесенкой (dig_at + place_at), при неудаче столбом (pillar_up), со счётом блоков до старта (need/missing). Конфликт y/target_y/to_y — ok:false с вопросом «цель 31 или 72?»; «уже на высоте» — ok:false с числами; ok:true только при реальном подъёме: в ответе at, from_y, to_y, levels + dug/placed/steps/pillars; прогон без блоков и ступеней — не успех. Моб ближе 6 м (по ходу и до старта) или HP<8 — остановка с причиной, без побега (случай 20261022-174642-95). При успехе возвращает {ok:true, at, from_y, to_y, levels, dug, placed, steps, pillars, need, have, missing, why}; при провале — {ok:false, error, at, goalY, why, need/have/missing по месту}.
Ограничения: лесенка требует место впереди-вверху и блоки в инвентаре (≈1.5 на уровень + 5); столб — только блок, который берёт тело; лава/вода в колонке — сторона пропускается; ground=1 без видимой поверхности — отказ с причиной; побега при мобе/низком HP навык не делает — тело отдаёт мозгу.
