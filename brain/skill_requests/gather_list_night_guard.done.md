# gather_list_night_guard: готово
Версия: gather_list_v4 (новая версия взята как v3 + проверка обстановки)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=gather_list_v4"
Params: items — список предметов; max_sec — время (по умолчанию 600); dry=1 — только план
Что делает: добавляет проверку окружения перед сбором: ночь — отказ, hostile моб ближе 10м — отказ, HP < 8 — отказ. При перехвате задачи (shelter/escape) возвращает ok:false с причиной и прекращает сбор. Не автоматически вызывает explore, если блок не виден.
Что вернёт при успехе: {ok:true, collected, crafted, missing...}; при провале: {ok:false, error: 'ночь: сбор не начинаю' / 'моб X.Y м рядом: сбор не начинаю' / 'HP < 8: collect не начинаю'} + сбор остановлен
Ограничения: не начинает collect/explore ночью и при враждебном мобе рядом; если collect не видит блок — не вызывает explore автоматически, а возвращает отказ с причиной «ищи в другом месте»; останавливает работу когда задача тела перехвачена другим навыком

Ограничения: чего навык не умеет / что должно быть в инвентаре: сбор ночью запрещён, сбор при мобе <10м запрещён, HP<8 запрещен, automatic explore blocked when block not visible
