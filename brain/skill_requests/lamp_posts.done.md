# lamp_posts: готово

Запуск: `curl.exe -s "http://127.0.0.1:3200/go?name=lamp_posts&x1=-406&z1=25&x2=-399&z2=25&y=68&dry=1"`

Params: `x1`,`z1`,`x2`,`z2` — концы линии (обязательно); `every` — шаг между столбами в клетках, по умолчанию 1; `y` — высота основания (слой 0 чертежа), по умолчанию 68; `name` — чертёж, по умолчанию `fence_post_lamp`; `dry=1` — только смета; `max_sec` — потолок времени, по умолчанию 600.

Что делает: идёт по клеткам линии с шагом `every` и ставит на каждой столб телом `build_blueprint` (`fence_post_lamp`: булыжник + 3 забора + факел, 5 блоков). Перед стройкой делает точную смету по каждой клетке (уже готовые столбы не считаются): при нехватке возвращает `{ok:false, missing:{…}}` и не начинает. Успех: `{ok:true, posts, at:[[x,y,z],…], failed:[]}`; частичный провал: `{ok:false, error, posts, at, failed:[[x,y,z,причина],…]}`. `dry=1`: `{ok:true, dry:true, posts, todo, need, have, missing, total, enough}`.

Ограничения: нужен чертёж `brain/blueprints/<name>.txt` и навык тела `build_blueprint`; блоки (cobblestone, spruce_fence, torch) должны быть в инвентаре — навык не крафтит и не добывает; основание `y` должно опираться на твёрдый блок (бревно/парапет/настил); столбы не копает и ничего не ломает; конец линии попадает в список, только если её длина кратна `every`. Файл проверен через `/check` (`ok:true`), в игре не запускался.
