# build_partial: готово
Версия: build_partial (новый навык)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=build_partial&blueprint=hut_west&x=-403&z=33&y=67&dry=0"
Params: blueprint — имя чертежа, по умолчанию hut_west; x — x координата северо-западного нижнего угла постройки (для hut_west: -403); z — z координата (для hut_west: 33); y — y верхнего блока пола (для hut_west: 67); dry — 1 для сметы (ничего не строить, только вернуть need/have/missing/plan); max_sec — предел времени стройки в секундах (по умолчанию 900)
Что делает: Строит по чертежу hut_west частями, используя материалы, которые есть в инвентаре мухи. Сначала ставит пол и стены (снизу вверх, слой за слоем), затем крышу. Клетки, на которые материала в инвентаре нет, пропускаются и перечисляются в ответе в поле `missing`. Возвращает `{ok:true, placed:N, missing:{...}, need, have, plan, by_layer}`. Частичный успех (окили некоторых клеток поставлено) считается за успех (ok:true), навык не выключается за 3 провала подряд. Автопилот должен вызывать build_partial при провале build_blueprint с причиной «не хватает», вместо повторного отказа и ухода в разведку на 48 минут.
Ограничения: Не умеет ставить блоки, для которых в сумке мухи нет соответствующего материала. Требует корректных коорнат начала постройки. Клетки, уже стоящие на месте, не трогает и не пересчитывает заново. Прогон навыка не ухудшает постройку (стоявшие блоки не сносятся). Если в сумке нет ни одного нужного блока — возвращает отказ с причиной, а не «успех с нулём».
