# climb_up_alt_tunnel: готово
Версия: climb_up_v6 (новая версия рядом со старыми climb_up_v1 через climb_up_v5)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=climb_up_v6"
Params: need — явное число блоков на подъём (если не задано, считается ~1.5 на уровень + 5 в запас); item — из чего ступеньки (по умолчанию любой блок, но не столбовый); strict — 1 (по умолчанию) не начинать без блоков, 0 — начинать и разбираться по ходу; dry — 1 ничего не копать, только смета; max_sec — таймаут в секундах (по умолчанию 240); steps — макс. ступеней (по умолчанию 40)
Что делает: поднимается вверх из пещеры/канализации двумя способами: (1) обычная лесенка впереди-вверху + ступенька place_at, (2) NEW: подъём лестницей в стене с выходом сбоку — ищет сторону стены, где можно пробурить туннель к поверхности, копает ступеньками и взбирается в туннеле; цель — выйти на поверхность, а не достичь вертикальной высоты y=67; при неудаче fallback на pillar_up (подъём на месте); если выход сбоку невозможен (стена кончилась, лава/вода, блоков нет) — возвращает ok:false с числовой причиной
Ограничения: навык не умеет автоматически выбирать сторону туннеля если вокруг везде потолок; требует блоков в инвентаре (или strict=0 чтобы собрать по ходу); левая/правый выбор стороны зависит отLayout пещеры; не подходит для подъёма на большую высоту без Enough blocks; HP<8 вызывает escape; моб рядом — прекращает с причиной; инвентарь перечитывается после каждого блока
