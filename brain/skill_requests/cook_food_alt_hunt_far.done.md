# cook_food_alt_hunt_far: готово
Версия: cook_food_v5 (новый вариант навыка cook_food; за основу — текущая cook_food без версии, лучшая по счёту в каталоге; параллельная cook_food_v4.js на диске не зарегистрирована, её не трогал)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=cook_food_v5&min=8"
Params: min — сколько готовой еды нужно, по умолчанию 8; dry — 1 = только посчитать; hunt_radius — радиус охоты, м, по умолчанию 48; place — имя места с дичью для журнала/отказа, по умолчанию «лес»; x/y/z — координаты места охоты, по умолчанию лес -352 66 74; step — длина перебежки/смены точки, м, по умолчанию 14; min_hp — ниже нельзя идти к месту, по умолчанию 10; min_food — ниже нельзя далеко идти, по умолчанию 6; max_sec — потолок времени, по умолчанию 480.

Что делает: жарит сырое мясо в печи; если готовой еды < min и мяса нет — первая охота рядом (как раньше, hunt radius 48), пусто — сама перебежками по 14 м с survey у каждой шага (обрыв вниз >3 м / подъём >2 м не перешагивает, ПЕРЕД каждой перебежкой проверяет ночь и HP, к краю ближе 8 м обзора не уходит) идёт к известному месту с дичью (лес -352 66 74, можно задать x/y/z/place) и охотится оттуда; на месте — до 2 охот с одной безопасной сменой точки между ними. Успех — {ok:true, ready, cooked, kills, places:[имя+адрес каждой точки], lastSpot}. Отказы честные, «место» — всегда адрес (координаты), без «смен мест» и без «выбрать сторону самому»: ночь («ночь: охота не идёт вообще», и до леса тоже, в журнале — координата, где остановилась), пещера/под крышей/под землёй (крыша над головой 5×5 не из листвы/брёвен survey'ом вверх y+1..y+7 — отказ сразу, без спуска и без дороги), HP < min_hp, сыть < min_food, «путь не виден» / не добралась (адрес, где осталась), «дичи нет и здесь: лес (-352 66 74)».

Ограничения: нужно топливо для печи (без него отказ сразу, как раньше); hunt тела ищет только среди известных сущностей — если мозг впервые видит лес и там никого не встречали глазами, охота может быть пустой (тогда честный отказ, с адресом); дорога идёт к заданной точке существующим goto тела — к обрывам/препятствиям навык отворачивает только ±45°/±90°, глубокий обход не умеет; кровь/урон в пути не обрабатывает сама (рефлексы тела — отступают, потом отказ по HP/ночи).
