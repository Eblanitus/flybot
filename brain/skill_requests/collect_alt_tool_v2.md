# collect_alt_tool_v2 — от учителя
Что не так: skill `collect` падает с ошибкой «нужен инструмент для cobblestone: wooden_pickaxe», когда в инвентаре нет деревянной кирки, из-за чего build_blueprint стоит, муха простойт, и сбор отменяется рефлексом. Текущий collect проверяет инструмент только для первого блока, а не для всех в списке.
Доказательства: signal #1455 (build_blueprint провалился: не хватает cobblestone ×77); events.log #1459-1478 (task collectStarted/Done x3, каждый раз «навык тела 'collect' не удается: нужен инструмент для cobblestone: wooden_pickaxe»); runner.log #30 (#3535) gather_list run для cobblestone:77 с ошибкой «не добрал: cobblestone x66 (cobblestone: навык тела 'collect' не удается: заменён навыком escape)»; day_report idle 156 мин, built 0.
Кто решил: skill:collect (тело) — падает без инструмента; autopilot — assigner cobblestone для build_blueprint; reflex — прерывал collect мобами.
Версия: новый вариант collect_alt_tool_v2 (гарантирует инструмент ВСЕХ блоков в params collect перед началом добычи, а не только первого). отличается от collect_tool: проверка всех блоков списка; отличается от collect_alt_tool: универсальный подход ко всем типам блоков, а не адаптирован под hut_west-микс.
Что нужно: муха должна обеспечивать инструмент спереди для ВСЕХ блоков в параметрах collect, а не отдавать задачу и падать при отсутствии инструмента; приоритет завершения collect перед тем, как reflex прервёт задачу при добыче.
Вариант: новый вариант: collect_alt_tool_v2 — skill collect с обеспечением инструмента спереди для всех блоков списка. Подходит, когда collect_params содержит cobblestone/stone/coal и кирки нет (после смерти, в новом мире или после долгого простоя); отличие от collect_tool: проверяет ВСЕ блоки из списка, а не только первый; отличие от collect_alt_tool: не адаптирован только под hut_west, а работает для любого набора блоков.
Простая до: 20 мин (текущий день), самый длинный 156 мин (days.log, день 10); построено за сутки: 0.
