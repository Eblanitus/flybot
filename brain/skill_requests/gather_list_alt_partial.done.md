# gather_list_alt_partial: готово

Версия: gather_list_v5 (новая версия alongside старые v1-v4)

Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=gather_list_v5&items=cobblestone:8,spruce_planks:8,glass_pane:5"

Params:
- items: список "имя:кол-во,…" или объект {имя:n}; числа: "name:N" = довести до N, "name:+N" = добавить N к имеющемусье; синонимы: stone=cobblestone, log=брёвна, planks=spruce_planks, coal_ore=coal
- max_sec: ограничение времени, по умолчанию 600
- dry: 1 — только посчитать need/have/missing и план

Что делает:
- Собирает весь достижимый список: если в items встречается неизвестное имя (например glass_pane), навык не отменяет всю задачу, а собирает всё что может (cobblestone, spruce_log, spruce_door, torch, spruce_planks), а неизвестное возвращает в missing/unknown с подсказкой
- Отказ ok:false только если собрано НИЧЕГО (collected пусто)
- Число в items поддерживает два смысла: "cobblestone:101" = довести инвентарь до 101 штуки (как раньше), "cobblestone:+37" = добавить 37 к тому, что уже есть в инвентаре — тогда вызывающий не сможет ошибиться: автопилот даёт дельту, навык ждёт итог, и добор не становится пустым
- Стекло делается_self:collect sand → smelt (печь, тело делает само) → glass → panels крафтом (6 стекло → 16 панелей). Если цепочка не идёт — отказ с причиной («нет печи», «нет угля», «песка не видно»), а не «не знаю, как получить». Для окна хижины хватает целого стекла
- В ответе всегда указывается: collected (что собрано), crafted (что скофчено), missing (чего не хватало), unknown (неизвестные имена с подсказками)

Ограничения:
- Неизвестное имя не «сдаётся сразу» — проверяется один раз и сообщается с ближайшим Knownым аналогом (как stone→cobblestone), но не отменяет остальной сбор
- Стекло требует наличия печи и топлива (угля/досок); если нет — отказ с четкой причиной
- Число +N (дельта) работает только когда в инвентаре уже естьsome количества этого предмета
- dry=1 возвращает план сборки без выполнения

Что вернёт при успехе:
```
{ ok: true, collected: { cobblestone: 16, spruce_log: 4 }, crafted: { spruce_planks: 8 }, missing: {}, unknown: {}, sec: 45 }
```

Что вернёт при частичном успехе (есть неизвестные, но есть и собранные Items):
```
{ ok: true, collected: { cobblestone: 16 }, crafted: {}, missing: { glass_pane: 5 }, unknown: { glass_pane: { count: 5, have: 0, suggest: 'sand' }, collected: {} }
```

Что вернёт при провале (ничего не собрано):
```
{ ok: false, error: 'не добрал: glass_pane x5. Умею добывать/крафтить: cobblestone, spruce_log, ...', collected: {}, crafted: {} }
```
