# behavior_reflexes_escape_owner: готово

Версия: поведение (не навык), новая версия behavior рядом со старыми. За основу взята текущая версия behavior/.

Запуск: это правка поведения, включается без перезапуска тела:
`curl.exe -s -X POST -H "Content-Type: application/json" -d "{}" http://127.0.0.1:3199/behavior/reload`
(состояние: `curl.exe -s http://127.0.0.1:3199/behavior`).

Проверено: `node test/behavior.js` — ОК.

Что изменено (`behavior/reflexes.js`):
1. В обработчике `player_attack` добавлена проверка расстояния до игрока при нахождении в укрытии (`inShelter(ctx)`): если игрок находится вплотную (`playerDist < 3` м, например атака с 1.1 м у входа), рефлекс больше не удерживает муху в состоянии «в укрытии, стою» (`hold: true`), предотвращая смерть с 0 HP на месте.
2. При близком расположении игрока и низком здоровье рефлекс выбирает укрытие или путь на базу (`goto` / `shelter`) вместо бездействия.

Что делает: при атаке игрока, если игрок находится вплотную (< 3 м) даже в укрытии, рефлекс отменяет удержание на месте и запускает активную защиту (побег или отход к базе/укрытию).
