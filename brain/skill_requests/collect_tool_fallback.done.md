# collect_tool_fallback: готово
Версия: collect_tool_fallback
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=collect_tool_fallback&block=cobblestone&count=10"
Params: block — имя блока (cobblestone, stone, spruce_log и др.), по умолчанию cobblestone; count — количество, по умолчанию 1; items — альтернатива block/count в формате "block:count,..."; radius — радиус поиска, по умолчанию 48; deep — копать в глубину true/false; style — стиль копки auto/...
Что делает: Перед сбором stone/cobblestone проверяет наличие кирки (wooden_pickaxe/stone_pickaxe); если нет — крафтит её по цепочке (бревна→доски→палки→верстак→деревянная/каменная кирка). Для spruce_log проверяет видимость блока через eyes.blocks; если не виден — запускает explore к лесу. Если при сборе stone получает ошибку «нужен инструмент» и крафт невозможен — переключается на fallback-блоки без кирки (log, dirt, sand). Возвращает {ok, collected, crafted, errors?, sec}. При успехе ok=true с собранными/скрафченными предметами; при провале ok=false с error и деталями.
Ограничения: Нужен доступ к верстаку (крафтит сам если есть доски); для крафта кирки нужны бревна (минимум 3 ед. дерева); explore может не найти дерево; не копает руду в глубине без кирки; при полном отсутствии дерева — честный отказ «нет брёвен для крафта кирки».
