# gather_list: готово
Версия: gather_list_v7
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=gather_list_v7&items=cobblestone:28,spruce_fence:2"
Params: items — список предметов и количеств ("имя:кол-во,..."); max_sec — ограничение времени (по умолчанию 600); dry — 1 для сухого прогона (план).
Что делает: Доберает недостающие предметы (крафт из имеющегося, добыча сырья через collect). Гарантирует строгую проверку: `ok:true` возвращается только если в инвентаре собраны абсолютно все запрошенные предметы (`missOf(inv)` пуст), исключая ложные успехи.
Ограничения: Требует правильных имён или синонимов, инструментов для добычи сырья (кирки для камня) и времени в пределах max_sec.
