# collect: готово
Версия: collect_v2 (за основу взята collect_v1)
Запуск: curl.exe -s -H "Content-Type: application/json" -d "{\"name\":\"collect_v2\",\"params\":{\"block\":\"cobblestone\",\"count\":1}}" http://127.0.0.1:3200/run
Params: block — имя блока для сбора (по умолчанию cobblestone); count — количество, по умолчанию 1; items — список в формате "block:count, ..."; radius — радиус сбора, по умолчанию 48.
Что делает: Собирает указанный блок с автоматическим обеспечением инструментом (проверка и крафт деревянной кирки, с вызовом `explore` и перебором типов брёвен `spruce_log`/`oak_log`/`birch_log`/`log` при нехватке дерева). Возвращает `{ok: true, collected, crafted}` при успехе и `{ok: false, error}` при провале.
Ограничения: Требуется наличие доступа к деревьям в мире для добычи начальных брёвен при отсутствии кирки.
