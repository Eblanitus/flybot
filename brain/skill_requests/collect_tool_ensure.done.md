# collect_tool_ensure: готово
Версия: collect_tool_ensure
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=collect_tool_ensure&block=cobblestone&count=2"
Params: block — имя блока для сбора (по умолчанию cobblestone); count — количество (по умолчанию 1); items — список в формате "block:count, ..." (альтернатива block/count); radius — радиус сбора (по умолчанию 48); deep — копать в глубину (true/false); style — стиль копки (auto).
Что делает: Собирает указанный блок с гарантированным обеспечением деревянной кирки спереди. Сначала проверяет, нужен ли инструмент для добываемого блока (cobblestone, stone, coal_ore и др.). Если инструмента нет — последовательно обеспечивает: spruce_log → spruce_planks → stick → crafting_table → wooden_pickaxe, и только затем копает requested block. ensure_tool сохраняется в состоянии задачи до completion, не сбрасывается при переключении task'ов. gather_list блокирует build_blueprint до тех пор, пока cobblestone/spruce_log количества sufficient в inventory build_blueprint'a. Возвращает {ok: true, collected, crafted: {wooden_pickaxe: 1}, pickaxeEnsured: true, sec} при успехе или {ok: false, error} при нехватке материалов.
Ограничения: Треет наличия деревьев/брёвен в радиусе досягаемости для крафта кирки, если её нет. Честный отказ с причиной «нет брёвен для крафта кирки», а не «нужен инструмент». Инструмент обеспечивается один раз на задачу — при переключении task'ов состояние не сбрасывается.
