# climb_stairs: готово

Версия: climb_stairs_v3 (взята за основу climb_stairs — текущая на 22.10, «как v2 + подъём на месте»)

Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=climb_stairs_v3&steps=8&dir=east&target_y=70&item=cobblestone"

Params: steps — сколько ступеней максимум (по умолчанию 40); dir — направление east|west|north|south (по умолчанию east; при застревании пробуются перпендикулярные стороны); target_y — целевая высота ног (по умолчанию 66); item — материал пола (по умолчанию cobblestone; если нет — любой блок из набора dirt/stone/сосна…); from_y — стартовая высота ног, если муха в яме (по умолчанию из снимка); stuck_limit — шагов подряд без роста высоты до провала (по умолчанию 3).

Что делает: поднимается на target_y, ставя пол 1x1 на уровень ног впереди себя; если place_at отказывает («не к чему прислонить») — ставит опору снизу/сбоку и повторяет; если опоры нет — копает ближайшую стену dig_at и/или поднимается pillar_up, отказывающая клетка помечается и больше не повторяется; «занято» своим блоком — идёт дальше, чужим (dripstone_block и т.п.) — выкапывает. Возвращает ok:true с финальной высотой и статистикой, при провале — ok:false с error (шаг, клетка, причиной) и списком отказов; лог пишет клетку и причину каждого отказа.

Ограничения: нужны блоки в инвентаре (по умолчанию cobblestone, иначе любой подходящий); место постановки должно быть в досягаемости (~5.5 блоков); лава/вода в колонке ступени — остановка с причиной; без блоков для пола — провал.
