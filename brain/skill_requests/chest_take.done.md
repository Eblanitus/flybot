# chest_take: готово

Версия: chest_take_v7 (основа: chest_take_v5 — текущая chest_take 22.10); chest_open_v8 (основа: chest_open_v6 / текущая chest_open 22.10), chest_store_v7 (основа: chest_store_v5), deposit_v3 (основа: deposit_v2). Старые версии не трогались.

Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=chest_take_v7&item=spruce_log&count=1&x=-392&y=67&z=35"

Params:
- item — что взять (по умолчанию — показать только содержимое)
- count — сколько взять (по умолчанию — всё)
- x, y, z — координаты сундука (необязательно; иначе видимый глазами или известный)
- search — 1 (по умолчанию) — по заданным координатам сундука нет? ищет ближайший известный контейнер сам и берёт из него; 0 — отказ сразу
- dig_above — 0 не копать / 1 (по умолчанию) копать мягкий блок над сундуком / 2 любой кроме контейнера
- hand — auto (по умолчанию) / toss / skip
- walk_sec — сколько секунд идти, по умолчанию 20
- open_sec — сколько ждать окно сундука, по умолчанию 5 (мин 2, макс 20)
- dry — 1 — только показать, что мешает, ничего не открывая

Что делает: готовит муху к сундуку (осмотр, подход, блок над сундуком, сбоку, уровень, рука). Если по заданным координатам сундука нет (клетка не контейнер или не видно) — сам ищет ближайший известный контейнер (глаза → goto_known kind=chest) и открывает его; в ответе subst — какие координаты пусты и какой контейнер взят («сундук X Y Z, в N м»). Если координат нет и сундук не найден — ошибка со списком известных контейнеров из памяти тела (known), чтобы мозг не перебирал клетки наугад. Один отказ на один факт: «по координатам X Y Z сундука нет» + что о клетке известно (видно cobblestone / не видно) + что делать (назови координаты / зови без координат). То же для chest_store (chest_store_v7) и deposit (deposit_v3) — они зовут chest_open_v8.

Успех: {ok:true, chest:[x,y,z], took/item/stored, content, fly, held, above, subst?}. Провал: {ok:false, error:'…', known?, blocker}.

Ограничения: ищет только видимые глазами или запомненные тела сундуки (не ищет неизвестные/скрытые за чанком); не открывает, если над сундуком твёрдый блок и нельзя копать, сбоку занято, муха не встала на уровень, в руке блок без не-блока в инвентаре; тело должно быть свободно от других навыков.
