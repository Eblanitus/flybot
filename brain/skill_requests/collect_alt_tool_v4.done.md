# collect_alt_tool_v4: готово

Версия: collect_alt_tool_v4 (новая версия по заявке учителя)

Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=collect_alt_tool_v4&block=cobblestone&count=1"

Params:
- block — имя блока для сбора (cobblestone, stone, coal_ore и др.)
- count — количество, по умолчанию 1
- items — список в формате "block:count, ..." (альтернатива block/count)
- radius — радиус сбора, по умолчанию 48
- deep — копать в глубину (true/false)
- style — стиль копки (auto и др.)

Что делает: 2–4 строки:
На входе проверяет, нужны ли инструменты для ВСЕХ блоков в params (cobblestone, stone, coal_ore и др.). Если инструмент нужен — обеспечивает деревянную кирку спереди цепочкой крафта: spruce_log → spruce_planks → stick → crafting_table → wooden_pickaxe. В отличие от обычного collect, шаг обеспечения инструмента не возвращается как ошибка «нужен инструмент». В отличие от collect_alt_tool_v2, учитывает специфическую ошибку «wooden_pickaxe: не хватает: wo» (недостаток木料, а не инструмента вообще). Если брёвна недостаточно — честный отказ «нет брёвен для крафта кирки», а не «нужен инструмент». Если список можно выполнить без инструмента (только доски/брёвна) — старая логика без инструмента работает. В ответе видно, что инструмент был сделан (crafted: wooden_pickaxe) и сколько блоко собрано (collected.cobblestone / collected.stone).

Ограничения: навык не умеет копать без обеспечения инструмента спереди при наличии блоков, требующих кирку; если брёвна нет в инвентаре и вокруг — возвращает ошибку про недостаток木料; не работает как автоматическая заменаcollect_tool, это отдельный вариант с гарантированным обеспечениемTool спереди для всех блоков списка.

Схема обеспеченияTool: spruce_log (сломал голыми руками) → spruce_planks (крафт из 4 логов) → stick (крафт из 2 досок) → crafting_table (крафт из 4 досок) → wooden_pickaxe (крафт из 3 досок + 2 палок).
