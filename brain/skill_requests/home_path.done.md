# home_path: готово

Версия: home_path_v5 (база — текущий home_path, до правок не выпускался как версия; старые home_path_v1..v4 не трогались)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=home_path_v5&route=-100,68,36;-160,68,36;-220,68,36;-280,68,36;-340,68,36;-393,67,36&x=-393&y=67&z=36&surface=1&night_wait=0&max_climb=6&max_y=100&timeout_sec=600"
Params: route — точки маршрута "x,y,z;x,y,z;…", по умолчанию туннельный тайга→база; x/y/z — финальная цель (по умолчанию -393/67/36); surface — 1 по поверхности через -330 68 36, 0 по туннелям; min_hp — ниже этого HP отказ, по умолчанию 8; regen_sec — ждать регена, по умолчанию 60; max_sec — лимит времени, по умолчанию 900; max_climb — подъём выше этого значения ищем обход, по умолчанию 6; max_y — потолок ПОДЪЁМА, по умолчанию 100 (если тело уже выше — спуск, а не отказ); night_wait — 1 переждать ночь, 0 идти и ночью, по умолчанию 1; max_escapes — бегств подряд, по умолчанию 2; step — длина шага планирования, по умолчанию 20; skip_failed — 1 пропускать непройденные точки, 0 — остановиться, по умолчанию 0.
Что делает: ведёт тело по заданному маршруту точек по порядку, каждый шаг планирует по survey, в гору выше max_climb не лезет (обход вбок), max_y — потолок только подъёма (выше потолка ищет спуск и ведёт вниз с логом «спускаюсь с y=…»), ночью/в сумерках с мобом рядом — укрытие сразу, бегство от моба не повторяет более max_escapes раз, при отказе заканчивает укрытием (wait_night/shelter). При успехе возвращает {ok:true, arrived:true, at, passed, sec, …}; при провале — {ok:false, error:'не дошла до <точка>: <причина>; …', sheltered, passed, sec}.
Ограничения: не умеет строить обходы если всё окружение выше max_y и нет пути вниз; shelter требует ~9 блоков земли/булыжника в инвентаре и не копает в воду/лаву; не ходит сквозь стены и не лезет на пики выше max_y; инвентарь должен содержать еду при HP<8.
