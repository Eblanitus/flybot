# collect_tool_alt_v3 — от учителя (новый вариант: сбор с надежным обеспечением инструмента)

Что не так: skill `collect` по-прежнему падает с ошибкой «нужен инструмент для cobblestone: wooden_pickaxe», когда в инвентаре нет кирки, даже если уже существовала заявка `collect_tool_alt_v2`. Новый цикл простоя подтверждает, что старый вариант не покрывает случай, когда инструмента нет совсем (после смерти, новый мир, долгий простой). Bot застрял в цикле: build_blueprint → fail → gather_list → collect → "нужен инструмент" → fail → idle. Дополнительно: `collect` падает с «не получается добраться до dirt: не дотянулся» из-за отсутствия инструмента и pathfinding confusion.

Версия: — (текущая версия collect по-прежнему падает без инструмента, даже после collect_tool_alt_v2). Новый вариант: `collect_tool_alt_v3` — skill collect с гарантированным обеспечением инструмента спереди и обработкой случая полного отсутствия материалов, отличается от collect_tool_alt_v2 более строгой проверкой fallback-текста и гарантированным выполнением цепочки инструментов на каждом вызове, а не только при первом.

Что нужно (не код):
- skill `collect` (новый вариант `collect_tool_alt_v3`) должен проверять, нужен ли инструмент для каждого блока в плане сбора
- если инструмента нет и есть брёвна/доски — crafting chain: spruce_log → spruce_planks → stick → crafting_table → wooden_pickaxe, затем копать requested block
- если брёмна нет рядом — отказ с причиной «нет брёвен для крафта кирки» (не «нужен инструмент»)
- если инструмент уже есть в инвентаре — шаг пропускается (idempotent)
- в ответе должен быть видно: crafted: wooden_pickaxe (да/нет), инструмент перед коллекцией был обеспечен, collected.cobblestone > 0
- обеспечение инструмента должно быть гарантированным на каждом вызове collect, а не только при первом запуске gather_list
- после обеспечения инструмента — сразу копать requested block без пауз на проверку инструмента

Вариант: новый вариант `collect_tool_alt_v3` — skill collect с гарантированным обеспечением инструмента спереди и idempotentной реализацией. Подходит, когда требуется cobblestone/stone/coal, а кирки нет (после смерти, в новом мире или после долгого простоя). отличается от `collect_tool_alt_v2` (там обеспечение не гарантировано на каждом вызове, здесь — гарантированное выполнение цепочки инструментов каждый раз) и от `collect_tool` (нет шага «инструмент», он встроен спереди гарантированно).
