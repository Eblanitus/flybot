# craft_gear_equip: готово

Версия: craft_gear_v1 (новый вариант, не копия craft_gear — та версия осталась нетронутой и работает как раньше)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=craft_gear_v1"
Params: нет (без параметров; сам вызов считается «мозг попросил»)

Что делает: снимок → смотрит, что в руке (snap.heldItem), и ищет оружие в инвентаре по рангу материала (wooden/golden → stone → copper → iron → diamond; меч выше топора того же уровня, trident как iron). Есть оружие и в руке не оружие (пусто/блок/палка/кирка/лопата/мотыга) — надевает лучшее через equip_item dest=hand (ничего не крафтит и не тратит) и проверяет свежим снимком, что оружие действительно в руке. В руке уже оружие не хуже — ok:true без действий («в руке уже оружие X — не хуже, ничего не делаю»). В ответе: hand (до/после), equipped, weapons (что нашла в сумке), phase, mobNear (ближайший враг, м) и лог «только надеваю оружие, в бой не лезу» — надеть меч ≠ начать бой. При успехе ok:true c equipped/hand; при провале ok:false с причиной.

Ограничения: не крафтит, не плавит, не двигается, не воюет, броню и щит не трогает; из сундука оружие не достаёт (только инвентарь); целая секунда-две на вызов. Оружия нет в инвентаре → ok:false «оружия нет: нужен крафт (в руке …)» — тогда крафт через старую craft_gear. Ночь/моб рядом в решение не входят — навык выполняет вызов всегда; мозг решает, когда звать (моб/ночь/после копки).
