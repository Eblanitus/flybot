# gather_tool_missing: готово
Версия: gather_list_v12 (основа: gather_list_v11)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=gather_list_v12&items=cobblestone:30&near=-393,67,36"
Params: items — список предметов; max_sec — тайм-аут (по умолчанию 600); near — точка стройки для leash; leash — лимит расстояния от точки (96); dry=1 — только расчет.
Что делает: Добирает список предметов с предварительным обеспечением деревянной кирки (через поиск брёвен в памяти `goto_known` и `explore` в пределах `leash`), если запрашиваются блоки, требующие кирка (камень, руды). При нехватке дерева и невозможности найти брёвна возвращает честный отказ без зацикливания. При успехе возвращает `ok:true`, собранное и скрафченное.
Ограничения: Требует доступности деревьев в радиусе `leash` или в памяти мира; при полном отсутствии деревьев и исчерпании шагов поиск прекращается с честным отказом.
