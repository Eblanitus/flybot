# Заявка: `lamp_posts` — фонарные столбы вдоль края моста (Этап 2.4)

ВАЖНО инженеру: не изучай `lib/` — примеры API в `brain/learned/home_path.js` и `brain/learned/build_column.js`.
Нужен один файл `brain/learned/lamp_posts.js`, использующий только `api.cmd(...)` и `api.snapshot()`.

## Задача
Поставить фонарные столбы (массивный вид: булыжное основание + забор + факел/фонарь) вдоль отрезка:
по одному столбу на каждой клетке линии от (x1,z1) до (x2,z2) с шагом `every` (по умолчанию 1).
Высота столба — 5 блоков (булыжник, 3 забора, факел сверху).

## Как делать
Уже есть чертёж `brain/blueprints/fence_post_lamp.txt` (1×1×5: булыжник, 3 spruce_fence, факел) и навык ТЕЛА
`build_blueprint name=fence_post_lamp x=<x> y=<y> z=<z> rot=0` — просто вызывай его:
`await api.cmd('build_blueprint', { name:'fence_post_lamp', x, y, z, rot:0 })`.
Чертеж ставится на «твёрдый сосед» — основание (y) должно быть на брёвне/парапете/настиле.

## Параметры
- `x1`,`z1`,`x2`,`z2` — концы линии; `every` — шаг (по умолчанию 1); `y` — высота основания столба (по умолчанию 68);
  `name` — чертёж (по умолчанию fence_post_lamp); `dry`=1 — только смета (сколько столбов и блоков нужно);
  `max_sec` (по умолчанию 600).

## Что вернуть
`{ok:true, posts:<сколько>, at:[[x,y,z],…], failed:[[x,y,z,причина],…]}`.
Не хватает блоков (булыжник/забор/факел/палки) — `{ok:false, missing:{...}}` и НЕ начинать (сначала собрать).

## Контекст (мой план)
Мост: настил y=66, парапет/брёвна на y=67 по краям z=25 и z=33, x=-406…-399.
Столбы ставлю на гребень края: `y=68` (основание на бревне/парапете), 16 штук (8 на z=25 и 8 на z=33).
Пример: `/go?name=lamp_posts&x1=-406&z1=25&x2=-399&z2=25&y=68&dry=1`
