# collect_log_missing: готово
Версия: collect_v3 (взята за основу collect_v2)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=collect_v3&block=log&count=4"
Params: block — имя блока для сбора (напр. log, spruce_log, oak_log), count — количество (по умолчанию 1), radius — радиус сбора (по умолчанию 48).
Что делает: Обеспечивает надежное обнаружение брёвен в радиусе сбора после приближения к цели: проверяет все типы брёвен (`LOG_TYPES`) с повторным снэпшотом и задержкой, автоматически определяет и использует фактически видимый тип брёвен, а также выполняет ретрай при временных ошибках обзора. При успехе возвращает `{ok: true, collected, crafted}`, при провале — `{ok: false, error}`.
Ограничения: Требует видимых или запомненных брёвен в пределах радиуса (или наличия леса для explore).
