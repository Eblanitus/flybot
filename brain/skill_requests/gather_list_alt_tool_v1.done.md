# gather_list_alt_tool: готово
Версия: gather_list_alt_tool_v1 (новая версия рядом со старыми)
Запуск: `curl.exe -s "http://127.0.0.1:3200/go?name=gather_list_alt_tool_v1&items=cobblestone:16"` (смета без сбора: `&dry=1`)

Params: `items` — список `"имя:кол-во,…"` или объект `{имя:n}`; `max_sec` — потолок времени, 600; `dry=1` — только план (ничего не собирает).

Что делает: обеспечивает инструмент перед добычей: если в списке есть предметы, требующие инструмент (камень/уголь/руда), а кирки нет — сначала craft-цепочкой делает деревянную кирку: бревно → доски → палки → верстак → каменная кирка, а потом собирает. Если ресурсов для инструмента нет (нет брёвен/досок/палок) — честный отказ с причиной про ресурсы, а не «нужен инструмент». В ответе видно что сделано по инструменту (crafted: spruce_planks/stick/wooden_pickaxe) и что осталось добыть. Сбор инструмента — часть добора, он не должен заканчиваться по причине «нужен инструмент». Не собирает инструмент если список можно выполнить без него (только доски/брёвна).

Успех: `{ok:true, collected:{cobblestone:16}, crafted:{stone_pickaxe:1}, missing:{}, have:{stone_cobblestone:...}, sec}`. Провал: `{ok:false, error:'нет брёвен рядом для крафта инструмента (нужно Spruce log)' / 'есть доски и палки, но нет каменных блоков для деревянной кирки (нужно 3 камня)' / 'инструмент не скрафтился Properly, продолжаем без него'}`; в ответе всегда есть collected (может быть пустым) и crafted (сделанные шаги).

Ограничения: обеспечение инструмента только когда в списке есть RAW-предметы (cobblestone/stone/coal/raw_iron/raw_copper/raw_gold/diamond); инструмент не собирается если список состоит только из досок/брёвен; если брёвен рядом нет — отказ с причиной про брёвна; верстак тела ставит само под рецепт; после скрафта инструмента продолжает сбор.

(dry=1): `{ok:true, dry:true, need, have, missing, raw, crafts, plan, renamed}`
