# build_hut_alt_finish: готово

Версия: build_hut_v12 (взята за основу текущая build_hut — она содержит правила двери-на-обрыве из заявки build_hut.md; в заявке на вариант ссылка на рабочую в момент случая build_hut.20261021180449-589.js). Старые версии build_hut_v1..v11 и build_hut не трогались, лежат рядом.

Запуск: `curl.exe -s "http://127.0.0.1:3200/go?name=build_hut_v12&x=-399&z=30&y=66&door=west&roof=planks&corners=log"` (проверка: `POST :3200/check {"name":"build_hut_v12"}` → ok, версия build_hut_v12.20261023103954-292.js)

Params: x, z — внутренний юго-западный угол хижины; y — верхний блок пола; door — сторона двери west|east|south|north (по умолчанию west; при обрыве навык предлагает другие); roof — planks|mixed (по умолчанию planks); corners — log|cobble (по умолчанию log); max_sec — лимит времени (по умолчанию 900); dry=1 — только расчёт need/have/missing, ничего не строить; cells — список клеток остатка [{"x","y","z","kind"?}] — если задан, ставим только их, иначе считаем недостающие по survey.

Что делает: достраивает хижину по остатку, НЕ пересобирая весь план 167 клеток — берёт недостающие клетки (из своих «последние дыр» по survey или из params.cells) и ставит только их (крыша/стены/пол). Стоящие блоки плана не трогает, не копает, прогон не ухудшает хижину. Под дверью, если клетка под ней пуста, ставит опору cobblestone/dirt и только потом дверь; если опору поставить нельзя (край обрыва) — честно отказывает в двери и предлагает door=north/south/east (решение за мозгом). При успехе возвращает {ok:true, left:{крыша:{left,total}, стены, пол, дверь:{placed,reason,suggest}}, message: «осталось: крыша N/M; стены …; пол …; дверь: …», placed, по слоям}. При провале материала — {ok:false, error:'не хватает: …; осталось N клеток: …», nothing placed; при мобе/ночи/низком HP — краткий отказ и тело отдаётся сразу.

Ограничения: не строит с нуля — если хижины ещё нет, нужен обычный build_hut; нужен материал в инвентаре (булыжник/доски на клетки, spruce_door на дверь, cobblestone/dirt на опору) — иначе отказ с missing, ничего не ломает; дверь на обрыве не ставится (предлагает другую сторону); не переносит хижину и не лечит уже сломанное. Живой прогон инженер не гоняет (только /check) — проверять должен мозг: dry=1, потом обычный запуск днём; в ответе должно быть «осталось: крыша N/M; дверь: …», а не «построено N/167», и список стоящих блоков survey до/после не должен уменьшиться.
