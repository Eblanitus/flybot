# collect_tool_alt_v3: готово
Версия: collect_tool_alt_v3 (основа: collect_tool_alt_v2)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=collect_tool_alt_v3&block=cobblestone&count=10"
Params: block — имя блока для сбора (cobblestone, stone, coal), по умолчанию cobblestone; count — количество, по умолчанию 1; items — альтернатива block/count в формате "block:count,..."; radius — радиус сбора, по умолчанию 48; deep — копать в глубину (true/false); style — стиль копки (auto и др.)
Что делает: гарантированно обеспечивает деревянную кирку спереди на КАЖДОМ вызове перед сбором блоков, требующих кирку (cobblestone, stone, coal, руды). Цепочка крафта: бревно → доски → палки → верстак → wooden_pickaxe. Если кирка уже есть — шаг пропускается (idempotent). Если нет брёвен рядом — честный отказ «нет брёвен для крафта кирки» (не «нужен инструмент»). После обеспечения инструмента сразу копает requested block без пауз. Возвращает collected, crafted (включая wooden_pickaxe: 1 если скрафчена), pickaxeEnsured (true если обеспечена), sec.
Ограничения: требует доступных брёвен (spruce/oak/birch) в радиусе сбора для крафта кирки; не умеет крафтить каменную/железную кирку (только деревянную); тело collect должно уметь добывать указанный блок; не решает за мозг, куда идти — только собирает по параметрам.
