# behavior_autopilot_zero_hp_idle: готово
Версия: behavior/ (автопилот)
Запуск: curl.exe -s -X POST -H "Content-Type: application/json" -d "{}" http://127.0.0.1:3199/behavior/reload
Params: —
Что делает: Исправлен автопилот для состояния HP=0 (критический минимум без еды): добавлено ограничение ожидания в укрытии до 2 минут (120 с), после чего автопилот не висит бесконечно в бездействии, а переключается на экстренный сценарий восстановления или сброса (возврат на базу, охота или экстренный поиск/разведка).
Ограничения: Требуется наличие доступных условий для экстренных действий (база, животные для охоты или свободный проход для разведки).
