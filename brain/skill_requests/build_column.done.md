# build_column: готово

Запуск: `curl.exe -s "http://127.0.0.1:3200/go?name=build_column&x=-401&z=28&from_y=66&to=water&size=2&block=cobblestone"` (смета: `&dry=1`)

Params: `x`,`z` — центр колонны (по умолчанию где стою); `from_y` — верх/настил, 66; `to_y` — низ числом (важнее `to`); `to` — `water` (по умолчанию) или `ground`; `size` — сторона 1..3, 2; `block` — `cobblestone`; `dry`=1 — только смета; `max_sec` — 600.

Что делает: survey вокруг, находит низ (воду и дно под ней / грунт / `to_y`), проверяет запас блоков. Строит СНИЗУ ВВЕРХ: встаёт на основание рядом, кладёт сечение `size`×`size` через `place_at` на каждом уровне, поднимается `pillar_up` (блоки-леса в соседней клетке). Ничего не копает и не ломает мост/парапет/лестницу/туннель.
Успех: `{ok:true, placed, cells, from, to, stop:'water'|'ground'|'to_y', scaffolds, filled}`. Провал: `{ok:false, error, holes?, stop:'lava'?}`; блоков мало — `{ok:false, missing:{<block>:N}}` и НИЧЕГО не строит (в `need` уже учтены блоки на леса).

Ограничения: нужен твёрдый пол у основания, чтобы встать рядом (иначе `некуда встать…`); сечение не больше 3; леса — отдельный столб рядом, в `placed` не входят; глубокую воду проходит со дна (следит за воздухом, при ttd ≤8 с и HP<8 останавливается); лава в колонне — стоп `lava`; блоки только одного вида, менять/добирать в процессе не умеет.
