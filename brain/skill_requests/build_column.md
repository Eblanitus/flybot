# Заявка: `build_column` — колонна вниз с моста к воде (Этап 2.3)

ВАЖНО инженеру: не изучай `lib/` (на это уходит весь лимит) — примеры вызовов API есть в
`brain/learned/home_path.js` и `brain/learned/bring_bed_home.js`. Нужен ОДИН новый файл
`brain/learned/build_column.js`, который использует только `api.cmd(...)` и `api.snapshot()`.

## Что делает навык
Строит колонну из блоков сечением `size`×`size` (по умолчанию 2×2) в точке (x,z):
сверху вниз от `from_y` (настил моста, 66) до `to_y`/`to=water` (вода y=38) — колонна упирается в воду/дно.
Вертикаль: мост x=-406…-399, z=25…33, настил y=66; щель под ним x=-399…-403, z=26…32.

## Алгоритм (кратко)
1. `survey` вокруг (x,z) — понять, где пусто, где дно/вода, где стоять.
2. Спуститься к основанию колонны: `api.cmd('goto', {x, y:to_y+1, z, timeout:120})`;
   если путь/вода мешают — `api.cmd('dig_at', ...)`/`api.cmd('pillar_up', {height:1})` по кругу,
   либо `api.skill('mine_stairs', {dir:'north', steps:12})`.
3. Строить СНИЗУ ВВЕРХ, уровень за уровнем (y от to_y до from_y-1):
   - поставить блоки сечения: `api.cmd('place_at', {x:cx, y:cur, z:cz, item:'cobblestone'})` для каждой клетки
     сечения (клетка должна быть в пределах досягаемости бота; сосед — уже поставленный блок/настил/стена);
   - поднять бота на следующий уровень: `api.cmd('pillar_up', {height:1, item:'cobblestone'})`
     (съедает блок из инвентаря — это и есть строительные леса рядом с колонной);
   - если `pillar_up` не смог (нет блоков/тесно) — попробовать поставить клетку уровня выше из текущей позиции.
4. Не ставить блок в клетку, где уже стоит правильный блок; не ломать мост (настил y=66), парапет y=67,
   лестницу базы (-394 52 36 -> -384 42 36), туннель (-395 38 22).
5. Стоп: вода/лава внизу (записать `stop:'water'|'lava'`), HP<8, кончились блоки.

## Параметры
- `x`,`z` — центр; `from_y` — верх (66); `to_y` (число) или `to`=`water`|`ground` (по умолчанию water).
- `size` 1..3 (по умолчанию 2); `block` (по умолчанию `cobblestone`); `dry`=1 — только смета;
  `max_sec` (по умолчанию 600).

## Ответ
`{ok:true, placed:<сколько блоков>, cells:<клеток>, from:[x,y,z], to:[x,y,z], stop:'water'|'ground'|'to_y'|'lava'}`.
Не хватает блоков — `{ok:false, missing:{cobblestone:N}}` и НИЧЕГО не строить.

## Пример
```
GET :3200/go?name=build_column&x=-401&z=28&from_y=66&to=water&size=2&block=cobblestone&dry=1
```
