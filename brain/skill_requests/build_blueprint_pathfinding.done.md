# build_blueprint_pathfinding: готово
Версия: build_blueprint_pathfinding
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=build_blueprint_pathfinding&blueprint=stair_down_1&x=-411&y=58&z=27&rot=0"
Params:
- blueprint — имя чертежа из brain/blueprints (по умолчанию stair_down_1)
- x, y, z — координаты угла постройки
- rot — поворот чертежа, 0 по умолчанию
- dry — 1 — только смета и план, ничего не строить
Что делает: Строит по чертежу с обработкой ошибок поиска пути («путь не найден») и нехватки опоры («нет опоры»): использует частичную стройку (`partial=1`) и обрабатывает тайм-ауты без бесконечного зависания. При успехе возвращает `ok:true` со статусом постройки и поставленными клетками; при частичной постройке или перехвате ошибок пути/опоры возвращает `ok:true, partial:true` и продолжит работу на следующем шаге.
Ограничения: Требует нужные материалы и блоки в инвентаре (или опору для подпорок). Навык проверен через `/check` (`ok:true`).
