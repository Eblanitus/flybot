# cook_food: готово
Версия: cook_food_v4 (за основу — cook_food, текущая; правка L030 сохранена и переделана, не откачена)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=cook_food_v4&min=8"
Params: min — сколько готовой еды нужно, по умолчанию 8; dry — 1 = только посчитать; hunt_radius — радиус охоты, м, по умолчанию 48; step — длина смены места, м, по умолчанию 12; max_sec — потолок времени, по умолчанию 420.

Что делает: жарит сырое мясо (smelt); мяса нет — охотится (hunt) и жарит. Отказ больше не врёт про смену места: «смен места N» = только реально выполненные смены (≥6 м), не вышло — «сменить место не вышло: <причина>» прямо в error (скрытого why нет). Ночью и под крышей/потолком (survey своей колонки вверх + sheltered) — отказ сразу: «ночь: охота не идёт, готовой еды N из M — пережить до утра», без hunt и без обещаний смены. Тот же вызов из той же точки: один раз сама уходит подальше (шаг в 2 раза, шаг через goto, не к краю), дальше — отказ «повтор запрещён»: память о провале — метка cook_food_fail (mark/waypoints тела, note «охота без животных #N: причина»; снимается на успехе). Подсказки мозгу — только действия мозга (goto/explore/climb_up/wait_night/go_home), «выбрать сторону самому» меньше нет. При успехе вернёт ok:true + ready/cooked/hunted/searched/attempts; при провале ok:false, error с причиной, счётчиками (искали N раз = реальные охоты), searched (где искали, не пустой) и missing.food.

Ограничения: если ответ «повтор запрещён» и уйти самой не вышло — мозг обязан сам сместить муху (goto/explore на 16–24 м) и позвать cook_food оттуда; навык тело сама волей-неволей без смены места не охотится. Топливо (уголь/доски/брёвна) должно быть в инвентаре. Метку-память cook_food_fail в waypoints тела мозгу не удалять (её снимает сам навык на успехе). Ночью/под землёй hunt не вызывается вовсе, поэтому ночные отказы повторяются честно (причина «ночь», не «животных нет»).
