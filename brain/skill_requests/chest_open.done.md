# chest_open: готово
Версия: chest_open_v7 (новая версия над chest_open v6)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=chest_open_v7&x=-392&y=67&z=35"  |  ok:false с error «по координатам -392 67 35 сундука нет, клетки не видно — назови настоящие координаты контейнера или найди сам (survey/explore)»
Params: x/y/z — координаты сундука (не заданы — найдёт видимый глазами или известный); search — 1 (по умолчанию) ищет ближайшийKnown при отсутствии по coord; 0 — сразу отказ; item — что хотим из сундука для known; dig_above — 0 не копать / 1 мягкий блок / 2 любой кроме контейнера; hand — auto/ toss/ skip; walk_sec — сек на подход
Что делает: находит сундук по coord/глазам/памяти, подходит, проверяет周围, копает над сундумом если нужно, освобождает руку, возвращает ok:false с error и known когда контейнера нет по заданным координатам (один факт: «по координатам X Y Z сундука нет, ...»); если контейнер найден Eyes/память — возвращает subst: какой контейнер, что внутри, и ok:false (не считается успехом); всегда в note указано: контейнер открыт / только подготовка / не найден
Ограничения: не встаёт дальше 25 м — сначала подведи муху (go_safe); ok:false когда сундука нет (счёт версии не растёт от подготовок); blocker — только реальные препятствия, а не «pomaha ne polomka»; version считается успешно only когда ready:true и контейнер готов к взятию
