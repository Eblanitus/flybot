# collect_shelter_eblanitus: готово
Версия: collect_eblanitus (для исправления — новая версия, старые collect/shelter не трогались)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=collect_eblanitus&block=cobblestone&count=2"
Params: block — имя блока для сбора (cobblestone, stone, coal, spruce_log и др.), по умолчанию 'cobblestone'; count — количество, по умолчанию 1; items — альтернативный формат списка блоков; radius — радиус сбора, по умолчанию 48; deep — копать в глубину (true/false); style — стиль копки (auto и др.)
Что делает: collect: 1) Проверяет, нужен ли инструмент для собираемого блока (cobblestone, stone, coal_ore и др.); 2) Если инструмента нет — обеспечивает его спереди цепочкой крафта: бревно→доски→палки→верстак→деревянная кирка; 3) Если брёвен рядом нет — честный отказ с причиной «нет брёвен для крафта кирки», а не «нужен инструмент»; 4) Копает requested block и возвращает результат с collected и crafted. shelter: проверяет наличие материалов для закрытия ямы перед стартом; если материал недоступен — приостанавливается с причиной «нет материалов для укрытия», а не «нечем закрыть яму».
Ограничения:collect: Треет наличия деревьев/брёвен в радиусе досягаемости для крафта кирки; не работает если нет материалов для цепочки досок/палок/верстака; честный отказ «нет брёвен для крафта кирки», а не «нужен инструмент».shelter: Треет наличия блоков для укрытия в инвентаре; при отсутствии материалов — приостановка с понятной причиной, а не провал.
