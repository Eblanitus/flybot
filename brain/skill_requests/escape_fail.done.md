# escape_fail: готово
Версия: behavior/reflexes.js (поведение — правка в месте, версионность через /behavior/reload)
Запуск: curl.exe -s -X POST -H "Content-Type: application/json" -d "{}" http://127.0.0.1:3199/behavior/reload
Params: — (поведение не имеет параметров запуска, настраивается через behavior/thresholds.js)
Что делает: При низком HP и атаке мобов (когда копка-укрытие слишком медленная из-за близости врага) рефлекс выбирает приоритетный экстренный побег, задействуя динамические стили (wall_escape, zigzag, sprint_away, pillar) для разрыва дистанции и избегания прямого боя. При успехе: муха успешно отступает и расталкивает дистанцию. При провале: возвращает ошибку, пробуя альтернативные варианты выживания.
Ограничения: требует наличия блоков в инвентаре для wall_escape или pillar при их выборе; при их отсутствии срабатывает fallback на sprint_away или zigzag.
