# gather_list_ensure_tools: готово

Версия: gather_list_ensure_tools (новая версия, взята за основу с нуля)

Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=gather_list_ensure_tools&items=cobblestone:32"

Params:
- items: список "имя:кол-во,…" или объект {имя:n}; синонимы: stone=cobblestone, log=брёвна, planks=spruce_planks, coal_ore=coal
- max_sec: ограничение времени, по умолчанию 600
- dry: 1 — только план, ничего не собирать

Что делает: gather_list_ensure_tools — собирает ресурсы с обеспечением инструмента спереди ПЕРЕД КАЖДЫМ сбором. Перед каждым вызовом collect проверяет, есть ли в инвентаре деревянная кирка (_pickaxe). Если кирки нет:
1. Собирает бревно (spruce_log), если нет — отказ с причиной «нет брёвен рядом»
2. Крафт досок из бревен
3. Крафт палок из досок
4. Крафт верстака, если нет
5. Крафт деревянной пики (wooden_pickaxe)
6. Только потом вызывает collect для запрашиваемого блока

Если список можно выполнить без инструмента (только досы/брёвна, не нуждающиеся в кирке) — используется старая логика без инструмента.

При успехе: ok:true, collected.cobblestone > 0, crafted содержит wooden_pickaxe, error отсутствует.
При провале: ok:false, error с причиной (например «нет брёвнов рядом — не сделать кирку» или «не добрал: cobblestone xN (нет древесины для крафта кирки)»), collected может быть 0, crafted может быть пустым.

Ограничения: 
- Навык не умеет Ensuring инструмента для предметов, не входящих в ITEMS_NEEDING_TOOL (только cobblestone, stone, coal, raw_iron, raw_copper, raw_gold, diamond)
- Если в инвентаре уже есть подходящая кирка — работает как обычный gather_list (без обеспечения инструмента)
- Обеспечение инструмента не завершается ошибкой «сначала нужен инструмент» — этот шаг встроен в навык
- Если брёвен недостаточно для крафта кирки — честный отказ с причиной «нет брёвен для крафта кирки», а не «нужен инструмент»
- Существующая логика без инструмента работает, если в.items только доски/брёвна (cobblestone/stone/coal/иные требующие инструмент нет)

Контекст: данный вариант решает проблему, когда gather_list падает с ошибкой «нужен инструмент для cobblestone: wooden_pickaxe», когда в инвентаре нет кирки. Новый вариант встраивает обеспечение инструмента спереди каждого шага сбора, а не только в начале, и дает честный отказ про отсутствие древесины, вместо误导ной ошибки «нужен инструмент».
