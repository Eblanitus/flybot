# gather_list_tool: готово
Версия: gather_list_v8 (основа: gather_list_v7)
Запуск: curl.exe -s "http://127.0.0.1:3200/go?name=gather_list_v8&items=cobblestone:32&max_sec=300"
Params: items — список "имя:кол-во,…" или объект {имя:n}; синонимы: stone=cobblestone, log=брёвна, planks=spruce_planks, coal_ore=coal; max_sec — ограничение времени, по умолчанию 600; dry=1 — только план.
Что делает: Собирает список предметов (крафт из имеющегося + collect сырья). Встроенное обеспечение инструмента: если в items есть блоки, требующие кирку (cobblestone, stone, coal, raw_iron, raw_copper, raw_gold, diamond) и в инвентаре нет кирки — сначала craft-цепочкой делает wooden_pickaxe (собирает бревна → доски → палки → верстак → кирка), затем collect. Если брёвен/досок/палок нет — честный отказ «нет брёвен для крафта кирки» (не «нужен инструмент»). В ответе видно crafted.wooden_pickaxe и collected.cobblestone. Если список можно выполнить без инструмента (только доски/брёвна) — старая логика без инструмента. dry=1 — только план.
Ограничения: Нужен доступ к брёвен для крафта кирки; collect требует видимости блока (нет рентгена); max_sec максимум 1800; навык не копает туннели за рудой — только collect по видимости/explore.
