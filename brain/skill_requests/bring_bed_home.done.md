# bring_bed_home: готово

Запуск: `curl.exe -s "http://127.0.0.1:3200/go?name=bring_bed_home&x=-394&y=67&z=33&points=-378,54,28;-558,71,41&route=-378,54,28&village_x=-529&village_z=22&timeout_sec=1200"`

Params: `x,y,z` — куда нести (по умолчанию -393 67 36); `points` — точки с кроватью через `;` (можно «-378,54,28;-558,71,41»); `route` — необязательные промежуточные точки маршрута (для целей дальше 60 м; назад идёт в обратном порядке); `village_x/village_z/village_y` — деревня; `prefer` — `bed` (по умолчанию) или `wool`; `place` — 1 (по умолчанию) поставить у сундука / 0 только принести; `max_sec` — потолок, 900.

Что делает:
1. Ищет кровать только как `*_bed` (red_bed, white_bed, …) через `survey` объёмом r=10/dy=4 и `eyes.blocks.bed`. Блока `bed` и вызова `find bed` больше нет; find нигде не используется, поэтому «неизвестный блок» невозможен.
2. Порядок: своя кровать в инвентаре → крафт из своих ниток/шерсти → кровати в `points` (с обходом ±9 м вокруг точки, если кровати не видно: дома деревни) → шерсть/нитки рядом (12 ниток → 3 white_wool → white_bed; пауки ≤12 м → fight+pictup; иначе `make_bed` с овцами) → деревня последней.
3. Перед любым крафтом сам проверяет доски (3) и шерсть (3 одного цвета) / нитки (12), доски делает из брёвен. `make_bed` без материалов больше не зовёт.
4. Дорога — перебежками по 22 м с проверкой `eyes.threats`/`enemies`; при таймауте `goto` обходит точку сбоку (2-я попытка), после 4 неудач бросает участок и идёт к следующей точке маршрута (маршрут не обрывается). Ночью кровать в руках не тратит: `shelter` + ожидание; без кровати — `wait_night`. Враги/HP<8 → `escape`.
5. Ставит кровать `place_at` на ровную клетку (воздух+воздух, твёрдый низ) ближе всего к сундуку базы, проверяет survey'ом.

Возврат: `{ok:true, bed:true, placed:true, at:[x,y,z], item, way:'inventory'|'point_bed'|'village_bed'|'wool'}`. Провал — `{ok:false, error, tried?, carrying?, at?}` (если кровать уже при себе, в `carrying` и `way`).

Ограничения:
- Кровать за стеной видна только после обхода: обход вокруг точки ограничен 60 с (точки) / 90 с (деревня); в глубине домов кровать может не попасть в survey.
- Не убивает пауков целенаправленно: берёт нитки только у пауков, которых уже видно ≤12 м (до 3 боёв).
- Не строит маршрут сам: промежуточные точки для каньона/деревни надо передать в `route`; без него — прямые перебежки с боковым обходом.
- Нужны 3 доски и 3 шерсти одного цвета либо 12 ниток; при `place=1` — свободное место у базы и сундук в радиусе 7 (иначе ставит дальше от центра).
- Тело сейчас offline (`:3199/snapshot` → ECONNREFUSED), запуск в игре не проверялся; `/check` — ok.
