## Чтение — ровно `curl.exe -s http://127.0.0.1:3199/<путь>` (или `:3200`), один параметр, без `&`, `-d`, `-X`
- `http://127.0.0.1:3199/snapshot` — `day` (стройка, простой), `autopilot` (`doing`, `goalFailed`), `task`, `eyes`, инвентарь.
- `http://127.0.0.1:3199/wait?timeout=240` — ждать важного события (до 300 с).
- `:3199/events?limit=40` — последние события; `:3199/autopilot` — дела автопилота и итоги; `:3199/memory?kind=iron_ore` — что муха видела.
- `:3200/catalog` (`?name=build_hut` — подробно) — выученные навыки; `:3200/log` — итоги их прогонов.
Действий (`/do`, `/cmd`, `/go`, `/run`, `/autopilot?on=` …) у тебя нет — их запрещают права.

## Строка цели для мухи
Раздел `## Текущая цель` в `notes.md`, строка `Автопилот: <навык> ключ=значение …` — следующий шаг стройки. Автопилот выполняет её у базы днём и ночью (чем дольше простой — тем охотнее): с новыми блоками — повторит; провал — повторит позже с шагом вдвое меньше; без нового блока — ждёт новую строку. Навык — из `/catalog` или навык тела. Примеры:
- `Автопилот: build_blueprint name=hut_west x=-398 y=66 z=28 rot=0` — постройка по чертежу `brain/blueprints/hut_west.txt` (x y z — СЗ-нижний угол; `rot` 0/90/180/270). Нет материала — провал с `не хватает: …`.
- `Автопилот: gather_list items=cobblestone:90,spruce_planks:30` — добрать материал ровно под шаг (крафт + добыча).
- `Автопилот: build_hut x=-397 z=29 y=66 door=west` — выученный строительный навык.
Порядок шага: смета `не хватает` → строка `gather_list` с этим списком → после успеха строка `build_blueprint`. Один навык в строке, параметры без пробелов внутри значения.
Строка `База: x y z радиус=N` (радиус по умолчанию 96) — центр стройки; днём муха дальше радиуса идёт на базу.
