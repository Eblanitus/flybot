# Чертежи построек (brain/blueprints)

Один файл = одна постройка: `brain/blueprints/<имя>.txt`. Мозг может рисовать новые сам (имя — латиница, цифры, `_`, `-`).
Строит их навык тела `build_blueprint` (описание вызовов — в `SKILLS.md`, раздел «Чертежи»).

## Формат в 5 строках
1. Мета и комментарии — строки с `#`: `# desc: …`, `# origin: NW-bottom` (точка привязки — северо-западный нижний угол, единственный вариант); остальное — просто комментарии.
2. Легенда до первого слоя: `C = cobblestone`, `S = spruce_stairs facing=west half=bottom` (блок и свойства `ключ=значение` как в F3). `. = air` есть всегда (вырезать); пробел = не трогать.
3. Слои снизу вверх: `layer 0`, `layer 1`, … (`layer 1-3` — один рисунок на три слоя). Слои можно пропускать.
4. Строки слоя идут с севера на юг (z растёт), символы в строке — с запада на восток (x растёт). Короткие строки добиваются пробелами.
5. Чтобы пробелы по краям строки не пропали, строку можно взять в `|…|`: `| ..C|` (в слое это 5 клеток, первая — «не трогать»).

## Пример
```
# desc: столб
B = cobblestone
F = spruce_fence
T = torch

layer 0
B
layer 1-3
F
layer 4
T
```

## Важное
- Привязка к миру: `build_blueprint x=… y=… z=… rot=0|90|180|270`. `x,y,z` — минимальные координаты постройки (СЗ-нижний угол) **после поворота**; слой 0 встаёт на высоте `y`.
- Поворот `rot` — по часовой стрелке при взгляде сверху (север сверху): при 90 северная стена чертежа становится восточной. Вместе с чертежом поворачиваются `facing`, `axis`, `rotation`.
- `facing` — как в игре: у ступеней и дверей это направление, куда смотрел игрок при установке (ступень `facing=west`: высокая спинка на западе). У факелов на стене и лестниц — в какую сторону «смотрит» блок (`wall_torch facing=east`: факел на западной стене светит на восток, опора — блок к западу).
- Дверь рисуется один раз (нижняя половина); клетку над ней оставь пробелом — верхняя половина достраивается сама.
- Блок слэба: `type=top|bottom` (`double` не поддерживается — нарисуй два слоя). Брёвна: `axis=x|y|z`.
- Сравнение «уже стоит правильно» учитывает имя и `facing/axis/half/type/rotation`; игнорируются `open`, `powered`, `waterlogged`, `hinge`, `shape` и подключения (стены, заборы, панели).
- Блоки без предмета (вода, лава, огонь) ставить нельзя; кровати, сундуки и т.п. в чертёж не рисуй (двигаются/ломаются иначе).
- Размер: до 64 блоков по каждой стороне и 8000 клеток.

## Примеры
- `hut_west` — хижина 7×7 (внутри 5×5): булыжник, еловые брёвна по углам, дверь на запад, 5 окон (стеклянные панели), 2 факела, крыша из досок.
- `fence_post_lamp` — столб 1×1×5: булыжник, 3 забора, факел.
- `bridge_segment` — мост 5×8: настил из досок, балки из брёвен вдоль моста (`axis=z`), перила-заборы, факелы на концевых столбах.
