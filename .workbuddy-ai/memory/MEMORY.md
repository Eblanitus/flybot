# Долговременные соглашения проекта flybot

## Работа с Claude Desktop Projects

- **Нового координатора можно делать только новым проектом.** Не новый чат в старом проекте, не дочерний чат-координатор. Один проект = один координатор. Старый проект после этого — архив, туда больше не пишут. Озвучено хозяином 06.11.2026.
- В новый проект переносятся только факты: короткая карточка состояния (до 4 КБ) + инструкции проекта. История чатов, project knowledge старого проекта, большие планы (`docs/goal_path.md`, `docs/stage2_plan.md`) и проектная память тредов не переносятся.
- Комплект: `new_project/README.md`, `new_project/PROJECT_INSTRUCTIONS.md`, `new_project/STATE.md`; генератор карточки — `tools/coordinator_state.js` (`node tools/coordinator_state.js`). Обновлять после каждого мира и серии коммитов.

## Порядок источников истины

Код и конфиги → карточка состояния → тесты → docs → проектная память → пересказы тредов. `docs/goal_path.md` и `docs/stage2_plan.md` — планы, не состояние; как текущее состояние не цитировать. Перед выводом сверяться с `git status` / `git log -1`.

## Запрещено без явного «да» хозяина

Запуск/остановка стенда, смена формулы очков, слияние PR, удаление файлов, правка `hardcore/config.json`. Обсуждать можно, трогать нет.
